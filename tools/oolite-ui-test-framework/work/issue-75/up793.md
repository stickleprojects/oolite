Yes, reproduced, and we have the cause and two tested fixes. Full write-up, timeline and screenshots: stickleprojects/oolite#75.

### Cause
The AppImage doesn't bundle libdecor. When libdecor isn't bundled, quick-sharun disables it by renaming SDL3's `libdecor-0.so` reference to a file that doesn't exist. GNOME doesn't draw title bars for native Wayland apps, so SDL3 has to draw its own, and it needs libdecor for that.

You're right that something in GNOME changed. SDL3 only uses native Wayland when the compositor offers the `fifo-v1` protocol ([SDL 3.4.18 source](https://github.com/libsdl-org/SDL/blob/release-3.4.18/src/video/wayland/SDL_waylandvideo.c#L523-L546)). GNOME 50 (Ubuntu 26.04) offers it; GNOME 46 (Ubuntu 24.04) doesn't. So on 24.04 the same AppImage runs through XWayland and GNOME draws the title bar, which is why the problem didn't show there.

### Two fixes
1. **Workaround for players now, no new build:** launch with `SDL_VIDEODRIVER=x11`. The game runs through XWayland and GNOME draws the title bar.
2. **Build fix:** three small changes to the AppImage build:
   - install libdecor with the AppImage build tools;
   - set `DEPLOY_SDL=1` in `create_appimage_fn.sh`, so quick-sharun bundles libdecor with SDL3 instead of disabling it;
   - pin `quick-sharun.sh` to a commit instead of `main` (as suggested in #777), so the build uses the quick-sharun that was tested.

   Fork PR: stickleprojects/oolite#81. No upstream PR yet.

### What we tested
Ubuntu 26.04.1 with GNOME 50.1 and Ubuntu 24.04.5 with GNOME 46.0, both full `ubuntu-desktop` installs in containers, in the default Wayland session. We ran 3 launches of each, and GNOME measured the window frame.

| Desktop | AppImage | Title bar |
|---|---|---|
| Ubuntu 26.04 | 1.93.1-253 | **none** (also seen by eye) |
| Ubuntu 26.04 | 1.93.1-253 with `SDL_VIDEODRIVER=x11` | yes |
| Ubuntu 26.04 | build fix, built on Arch (release path) | yes (also seen by eye) |
| Ubuntu 26.04 | build fix, built in `ubuntu:26.04` (CI path) | yes |
| Ubuntu 24.04 | 1.92.1.0 and 1.93.1-253 | yes (via XWayland) |
